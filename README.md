# Signal Garden Support

Public support and privacy pages for the Signal Garden iOS app.

This repository intentionally contains only static public documents. It does not
include app source code, build artifacts, credentials, analytics exports, App
Store Connect data, or private tester information.

Pages:

- Support: https://loredan1994.github.io/signalgarden-support/
- Privacy Policy: https://loredan1994.github.io/signalgarden-support/privacy.html

Support requests can be filed through GitHub Issues:

https://github.com/loredan1994/signalgarden-support/issues
